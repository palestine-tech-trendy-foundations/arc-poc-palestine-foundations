# Palestine Tech Trendy — Foundations Track

Two self-guided, fully autograded modules for complete beginners, built for the **Palestine Tech Trendy** program under the **ARC** curriculum (Istidama Consulting, DELTA v1.1 methodology).

No instructor review is required to complete these modules. Everything is graded automatically by GitHub Actions the moment you push your work.

## Modules

| Module | Topic | Estimated time |
|---|---|---|
| [Module 1](./module-1-git-hygiene/README.md) | Git Hygiene & Discipline | ~90 minutes |
| [Module 2](./module-2-python-github-foundations/README.md) | Python & GitHub Foundations | ~90 minutes |

## How this works

1. **You get your own copy of this repo** automatically when you enroll on Moodle (a background process forks this repo into your GitHub account — you don't need to do anything to trigger it).
2. **Clone your fork** to your computer:
   ```bash
   git clone https://github.com/<your-username>/palestine-tech-trendy-foundations.git
   cd palestine-tech-trendy-foundations
   ```
3. **Open the README for the module you're working on** and follow it step by step. Each module's README is self-contained — you don't need to read ahead.
4. **Push your work and open a Pull Request** when a module tells you to. A checker runs automatically and comments on your PR with a pass/fail breakdown within a couple of minutes.
5. **Fix anything that failed and push again** — the checker re-runs automatically on every push to the PR. There's no limit on attempts.

## Requirements

- A free [GitHub](https://github.com) account
- [Git](https://git-scm.com/downloads) installed on your computer
- [Python 3.10+](https://www.python.org/downloads/) installed (Module 2 only)
- A text editor (VS Code recommended, free)

No paid tools or subscriptions are required anywhere in this track.

## Getting help

These modules are self-guided by design, but if you get stuck on something that isn't a content question (e.g. Git itself won't cooperate), check the **Troubleshooting** section at the bottom of each module's README before anything else — it covers the most common beginner blockers.
